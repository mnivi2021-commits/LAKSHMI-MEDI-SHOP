Marketing CRM

Built for LAKSHMI SAFETY EQUIPMENT PRIVATE LIMITED

A web and mobile CRM for a safety-equipment distributor: annual and monthly targets by branch, area, division and sales person, daily sales entry, requests (lead, enquiry offer, order, DC, sample), follow-ups, payment collection, SMS and reports.

  • PHP 8.2
  • MySQL 8
  • Apache (XAMPP)
  • JavaScript
  • Expo / React Native
  • Role-based access
  • Excel import
